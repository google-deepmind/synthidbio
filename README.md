# SynthIDBio

[Figure 1: SynthIDBio Overview](SynthIDBio_Figure_1.pdf)

SynthIDBio is a family of methods for embedding highly detectable yet
function-preserving watermarks directly into biological sequences and
structures.

For more details, please refer to our paper: [Function-preserving biological watermarking of AI-generated protein sequences and structures](Link to paper - TODO).

This repository contains details on the various watermarking methods:
- [SynthIDBio-sequence](synthidbio_sequence/README.md): Details on watermarking protein sequences generated by watermarked ProteinMPNN.
- [SynthIDBio-structure](synthidbio_structure/README.md): Details on watermarking protein structures generated by watermarked AlphaFold3.
